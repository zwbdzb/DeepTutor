# ThinkBuddy 图标方案（2026-11）

三个方向，同一套色板。色板不是凭感觉调的，是从母品牌 Tokengine 的 favicon 逐像素统计出来的。

## 一、先定位问题

原始诉求是「深蓝太亮眼、没参考公司配色」。实测三个来源后，问题的准确定性是**色彩结构不一致**，而不是色相选错：

| 来源 | 主色（实测） | 点睛色 | 结构 |
|---|---|---|---|
| Tokengine 母品牌 | `#0C2484` `#006CB4` | `#F0D824` `#E45424` | **冷色大底 + 小面积暖色点睛**（双层） |
| 旧 ThinkBuddy（AI 稿） | `#18B478` → `#6CE4A8` | — | 单一绿渐变（单层） |
| 美工稿 | `#4B2BE8` 系 | — | 单色高饱和渐变（单层） |

母品牌之所以稳，靠的是「暖色只占不到 5%，其余交给深冷蓝」这个比例关系。美工稿把饱和度顶到最高且只有单层，于是并排看不像一家人，在白底界面上也扎眼。

**所以本方案的第一条纪律：暖色占比 ≤ 5%，只做点睛，不做底。**

## 二、三个方案

| | 方案 A（主推） | 方案 B | 方案 C |
|---|---|---|---|
| 形态 | 罗盘 Compass | 丝带 t | 对话气泡 + 暖火花 |
| 语义 | 方向、判断、取舍 | Think 的字母标记 | 对话、灵感 |
| 与美工稿关系 | 继承其「Compass」创意来源 | 继承其 t + Ribbon 骨架 | 继承旧标资产 |
| 16px 表现 | 需启用光学简化版 | 最好 | 需启用放大尾巴版 |

- **A 罗盘**：环＝表圈，双色指针＝判断的两面，缺口朝右上＝方向已定、向外生长。与「方向、判断、智慧」的定位直接同构，是三个里唯一能讲完整故事的形态；元素只有环、针、轴三个，24px 以上稳定；暖色只有一支指针，天然守住 5% 纪律。
- **B 丝带 t**：横杠右端上扬收笔，竖干为轴，单笔画构成。字母识别度最高、最不容易出错，代价是单字母标记较通用，缺少专属语义。
- **C 对话气泡**：保留用户已认识的「对话＋灵感」，切换成本最低、情绪最亲和。代价是气泡是全行业最通用的图标形状，差异化只能靠火花承担。

**建议**：选 A 做主标，B 作为小尺寸／单色场景的备用标记。若品牌切换成本优先，选 C。若希望延续美工方向，选 B。

## 三、色板 Token

| Token | 色值 | 用途 | 占比 |
|---|---|---|---|
| navy-deep | `#061A63` | 渐变起点（左上） | — |
| navy | `#0C2484` | 主色／单色底／文字 | 约 70% |
| azure | `#006CB4` | 渐变终点（右下） | 约 25% |
| amber | `#F0C81F` | 暖色渐变亮端 | ≤ 5% |
| ember | `#E45424` | 暖色渐变暗端 | ≤ 5% |
| white | `#FFFFFF` | 标记本体 | — |

渐变方向统一 135°（左上→右下），与母品牌 logo 的走向一致。

## 五、落地路径（选定后再执行）

图标散落在四个位置，换标必须四处同源，否则会出现「安装包图标变了但托盘没变」：

| 位置 | 用途 |
|---|---|
| `desktop-shell/assets/icon.ico` | 安装器 / exe 图标 / 任务栏 |
| `brand/logo/thinkbuddy-icon.ico` | 品牌源 ICO |
| `brand/logo/thinkbuddy-icon.png` | 品牌源 PNG（512） |
| `web/public/logo.png` | 前端页面内 logo |

替换顺序建议：`svg` → 导出 512 PNG 与多尺寸 ICO → 覆盖上述四处 → 重新打包。ICO 必须含 16/24/32/48/256，缺 16px 会在资源管理器小图标视图下糊。

## 六、被否决的方向（避免重复试错）

这些都在本轮做过并实测否决，不是没考虑：

| 尝试 | 否决原因 |
|---|---|
| 渐细丝带收尖的 t 尾 | 收尖后读作「拐杖／钩子」，不像丝带 |
| 暖色只染 t 的尾段 | 暖色块像粘在尾部的叶子，且面积越界 |
| t 的横杠全弧化（罗盘隐喻） | 整体读作雨伞／蘑菇，字母识别丢失 |
| 高饱和电子蓝紫（美工稿原配色） | 亮度顶格，白底刺眼，且与母品牌不同族 |
| 全暖色或暖冷对等的配色 | 直接退回「亮眼」问题，破坏稳重感 |
| 暖火花置于图标右上角（脱离标记） | 小尺寸下变成游离的橙色噪点 |
| 苏格拉底人像（手绘剪影 / 墨刻 / 正面面具） | 16px 全是无定形团块；128px 也只读出「一个老人」而非「苏格拉底」，泛指形象对品牌是负资产 |
| 石像做三阶／五阶墨块（版画化） | 模糊 + 分阶放大的是大理石纹理而非形体，读作地衣／迷彩 |
| 苏格拉底肖像做应用图标 | 32px 以下糊成色块，与 A 罗盘的 16px 表现不在同一量级 |

## 七、苏格拉底人像方向（衍生记录）

「能否从苏格拉底头像中抽象一个形象作为核心标志」这一问题做过完整实证，结论与全部失败路径记录在
[`socrates/README.md`](socrates/README.md)，含结论对照表 `socrates/verdict.png`。

一句话结论：**作为 16px 核心图标不能，作为 96px 以上的品牌人格资产能。**
核心图标仍用 A 罗盘（16px 成立，语义即苏格拉底式发问），苏格拉底肖像改作启动页／关于页／空状态／文档水印，
并在 `socrates/` 下交付深底与浅底两版肖像圆章。

## 八、学者头像方向（卡通人格层，已交付）

上节结论是「人像不能进图标」，但它有前提：**靠五官携带身份**。换成靠**道具**携带身份后，这个结论被推翻了一半。

`sage/` 下的学者头像（白须 + 圆墨镜 + 红色头戴耳机）把识别负载压到 3 项（2 个墨镜圆点 + 2 个耳机暖块 + 1 个白色外壳轮廓），
全部是面积驱动的纯色块，16px 仍能读出「戴耳机的人」。设计与全部迭代记录见 [`sage/README.md`](sage/README.md)。
另附该造型的**实拍照片抠图版**（`sage/photo/`），可与插画版配对使用。

分工因此变成三层：

| 层 | 标记 | 尺寸域 | 语义 |
|---|---|---|---|
| 核心图标 | A 罗盘 | 16px 起 | 产品的动作：判断方向 |
| 人格头像 | 学者头像 | 48px 起 | 产品的陪伴者：一起想 |
| 纪念性肖像 | 苏格拉底圆章 | 96px 起 | 思想源头：提问的传统 |

**16px 实测仍是 A 罗盘最强**（`sage/preview-16px.png`），故 `.ico` 主图标不建议更换；
学者的价值在于「用户愿意把它当头像」这件事，而头像永远 ≥ 48px。
